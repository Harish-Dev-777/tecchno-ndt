# TechnoNDT

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Set up environment variables:**
   Create a `.env` file in the root directory:
   ```env
   VITE_GET_QUOTE_API=YOUR_API_ENDPOINT
   VITE_CONTACT_FORM_API=YOUR_API_ENDPOINT
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
